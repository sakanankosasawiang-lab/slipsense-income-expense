☁️ ฐานข้อมูลกลาง (Cloud Database สำหรับซิงค์มือถือ & คอมพิวเตอร์)

          

            ⏳
            

              กำลังตรวจสอบการเชื่อมต่อ...
              
หากต้องการให้ข้อมูลในมือถือและคอมพิวเตอร์เป็นอันเดียวกันตลอดเวลา แนะนำให้เชื่อมต่อ Cloud Database (ฟรี เช่น Supabase / Neon)

            

          

          

            
วิธีเชื่อมต่อ Cloud Database ฟรีใน 1 นาที (Supabase / Neon):

            
    
              
  1. สมัครหรือเข้าสู่ระบบที่ Supabase.com หรือ Neon.tech (ฟรี)
    2. 
              
  2. สร้างโปรเจกต์ใหม่ แล้วคัดลอก Connection String (URI)
    3. 
              
  3. นำไปใส่ใน Vercel: เมนู Settings > Environment Variables ตั้งชื่อตัวแปรว่า DATABASE_URL
    4. 
              
  4. กด Redeploy — ระบบจะซิงค์ข้อมูลตรงกัน 100% ทุกเครื่องทันที!
    5. 
            

          

        


        


        
        

          
🤖 เชื่อมต่อ Gemini AI อ่านสลิปอัจฉริยะ (ตัวเลือกเสริม)

          

            ค่าเริ่มต้นแอปจะใช้ Tesseract OCR บนเครื่องฟรี 100% หากคุณใส่ Gemini API Key เพิ่ม ระบบจะสามารถใช้ Gemini Vision อ่านสลิปที่ยับหรือฟอนต์ซับซ้อนได้แม่นยำยิ่งขึ้น
