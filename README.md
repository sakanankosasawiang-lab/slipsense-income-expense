# 🧾 SlipSense - แอปรายรับรายจ่าย แนบสลิปแยกหมวดหมู่อัตโนมัติ

เว็บแอปพลิเคชันบันทึกรายรับ-รายจ่ายที่ใช้งานง่าย เพียงแนบรูปสลิปธนาคาร ระบบจะอ่านยอดเงิน ชื่อร้านค้า วัน-เวลา ด้วย **Tesseract OCR (ภาษาไทย + อังกฤษ)** และจัดหมวดหมู่ค่าใช้จ่ายให้อัตโนมัติ พร้อมรองรับการเชื่อมต่อ **Gemini Vision AI** เสริม

## ✨ ฟีเจอร์หลัก
- 📸 **สแกนสลิปอัตโนมัติ (Free Local OCR + AI):** รองรับสลิปทุกธนาคาร (K PLUS, SCB EASY, Krungthai NEXT, Bangkok Bank, TrueMoney ฯลฯ)
- 🏷️ **แยกหมวดหมู่อัจฉริยะ:** วิเคราะห์คำสำคัญจากชื่อร้านและบันทึกช่วยจำเพื่อแยกหมวดหมู่ทันที พร้อมระบบจดจำชื่อร้านใหม่ๆ อัตโนมัติ
- ⚡ **ปุ่มทดสอบสแกนสลิปตัวอย่างในคลิกเดียว:** ทดลองสแกนสลิป Cafe Amazon, 7-Eleven, ค่าไฟ PEA, ปั๊ม PTT, Shopee และสลิปเงินเดือนได้ทันที
- 📊 **Dashboard สรุปยอดและกราฟโดนัท:** ดูสัดส่วนค่าใช้จ่ายแต่ละหมวดหมู่ คลิกกรองตามหมวดหมู่และค้นหาย้อนหลังได้สะดวก
- 📥 **Export CSV:** ส่งออกข้อมูลรายรับ-รายจ่ายเปิดใน Excel ได้ทันที (รองรับภาษาไทยสมบูรณ์)

## 🚀 วิธีรันในเครื่อง (Local Development)

```bash
npm install
npm start
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

## ☁️ การ Deploy ขึ้น Vercel
โปรเจกต์นี้รองรับการ Deploy บน **Vercel** ทันทีผ่าน GitHub:
1. ไปที่ [Vercel Dashboard](https://vercel.com/new)
2. เลือก **Import Git Repository** จาก GitHub repo นี้
3. กด **Deploy** ได้ทันทีโดยไม่ต้องตั้งค่าเพิ่ม
